# HamroSampada

Scroll-driven walkthrough of **3D Gaussian Splatting** for Nepali heritage monuments — commentary sidebar + live WebGL capture viewer.

## Stack

- TypeScript · Vite · Three.js (WebGL) · SCSS · Yarn

## Develop

```bash
yarn
yarn dev
```

Open http://127.0.0.1:5173/

## Build / Vercel

```bash
yarn build
```

| Setting | Value |
|---|---|
| Root Directory | `.` (repository root) |
| Build | `yarn build` → `dist` |
